# Мышь в лабиринте

Java 21, Swing, Maven. Запуск: `mvn test`, `mvn package`, затем `java -jar target/OOPLaba2-1.0-SNAPSHOT.jar`. В IntelliJ запустите `org.example.Main` с JDK 21.

## Использование

1. Задайте размеры 2–200 и сгенерируйте лабиринт либо создайте пустое поле. Старт находится снизу слева, сыр сверху справа.
2. Редактор позволяет менять проходы, стены, воду, ток и переносить старт/сыр. После изменения поля обучение сбрасывается.
3. Награды: сыр +Z, одноразовая вода +x, каждый вход в ток −y, обычный шаг −1, столкновение со стеной −3. Требуется Z > x > 0, y > 0.
4. Нажмите «Обучить» и дождитесь завершения. «Стоп» прерывает обучение. Для автоматического движения необходим хотя бы один успешный обучающий эпизод.
5. «Показать маршрут» и «Шаг ИИ» используют лучший маршрут, действительно найденный при обучении. «На старт» сохраняет обучение и очищает текущие посещения. Ручное движение доступно без обучения при отключённом редакторе.
6. После успешного обучения показан прогноз суммы и минимальная награда за сыр для положительного итога. «Принять рекомендацию» меняет только выплату за сыр, сохраняя маршрут. Обычное «Применить награды» сбрасывает обучение.

## Генерация

Growing Tree создаёт связанные коридоры: в 25% случаев продолжается самая новая активная вершина, в остальных выбирается случайная. Это даёт больше ответвлений, чем длинный последовательный DFS. Затем открывается часть стен между соседними коридорами, создавая циклы и альтернативные пути. Специальные клетки размещаются после прорезания проходов. Узкие поля могут не иметь места для циклов. Достижимость сыра проверяется отдельно.

## Обучение и показ

Q-learning: α=0.25, γ=0.99, epsilon уменьшается с 0.9 до 0.05. Состояние включает позицию и выпитую воду. Только обучающие переходы обновляют Q-таблицу. В успешных эпизодах сохраняется стратегия; из найденных успешных эпизодов выбирается имеющий наибольшую сумму. Повторные выходы из одного и того же состояния заменяют предыдущие, убирая бесполезные циклы без потери собранной воды.

Показ НЕ запускает поиск пути по карте и НЕ получает готовый оптимальный маршрут. `RouteNavigator` читает только сохранённый обучением ход для текущей позиции и выпитой воды. Если успешных попыток не было, автоматическое движение и рекомендация награды недоступны. Если мышь вручную оказалась в неизвестном состоянии, показ останавливается. При показе и прогнозе Q-таблица не изменяется.

Абсолютный максимум очков и успех за фиксированное число эпизодов не гарантируются: качество маршрута зависит от исследования во время обучения. Выгодная вода включается, если обучением найден соответствующий лучший успешный путь. Это заменяет прежние независимые точные планировщики, которые решали лабиринт даже без обучения.

Обучение выполняется небольшими пакетами на EDT. Лимит эпизода: min(10000, строки × столбцы × 10). Лимит Q-таблицы: 100000 состояний; большое число водных клеток увеличивает пространство состояний.

## Подсветка

Все клетки текущей попытки, включая старт, отмечаются зелёным. Метки S/C/+ /·/! остаются видны; мышь рисуется поверх. Стены не отмечаются при столкновении. Возврат на старт, новое поле и сброс среды очищают историю. Обучающая среда отдельная, её посещения не окрашивают показанный пользователю маршрут.

## Классы и проверки

`Maze` — поле и генерация, `Environment` — награды и посещения, `QLearningAgent` — обучение и лучшая успешная стратегия, `RouteNavigator` — показ без поиска карты, `MazeFrame` — управление, `MazePanel` — отрисовка.

Тесты проверяют связность, альтернативные пути и развилки, формулу Q-learning, воду и штрафы, лучший реально обученный маршрут, отказ от показа без успеха, прогноз награды, зелёную подсветку и её сброс, работу окна. Для проверок без рабочего стола исключите `WindowTest`.
